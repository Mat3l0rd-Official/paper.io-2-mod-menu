How to install:

First you will need a sideloading tool.
Examples:
Sideloadly (Requires Computer)
Esign (No computer and need certificate)
Trollstore
Trollstore lite (Need to be jailbroken)

Esign Guide:
Download the ipa file
Open esign and import the ipa file.
it will show a prompt saying
Import app libary. Tap yes.
Then it will import to the app libary.
(IMPORTANT! You will need a certificate
to sign the app.)
Once it finishes importing then tap sign.
Then you are done!

Trollstore and Trollstore lite Guide:
Download the ipa file
Open trollstore or trollstore lite.
Tap the + button in the top right corner.
Tap “Import ipa file” then import it.
Then your done!
